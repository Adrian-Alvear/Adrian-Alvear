## Featured Projects

<details>
<summary><b>keyhints</b>: which-key popup and tmux-style window manager for Windows</summary>

<br/>

A keyboard-first layer for Windows. Press `Alt+Q` and a small popup lists the keys available next, including shortcuts for the app you are in, so shortcuts are learned by using them. Direct hotkeys focus, snap, resize, tile, and move windows across displays without the mouse.

| | |
|:--|:--|
| **Stack** | AutoHotkey v2 · Win32 API · Desktop Window Manager |
| **Scale** | Any number of windows across multiple displays; layouts for side by side, stacked, main + stack, and grid |
| **Performance** | Instant window moves with AutoHotkey's default 100 ms window delay removed; popup only renders when you pause |
| **Security** | Runs locally; no network access, no telemetry, no third-party code |
| **Impact** | Everyday window work becomes one or two keystrokes, and new shortcuts are discoverable on screen |
| **Repository** | [Adrian-Alvear/keyhints](https://github.com/Adrian-Alvear/keyhints) |

Nothing moves on its own: layouts apply only when requested, and every change can be undone. The engine is split into small modules (window actions, popup, focus outline), while menus and hotkeys live in two short, documented files so new shortcuts take one line each.

</details>
